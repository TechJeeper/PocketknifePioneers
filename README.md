# 🔪 Pocketknife Pioneers

A retro Oregon Trail-style spoof web game about collecting pocketknives, going broke, live Whatnot auctions, paper-test thumb slices, rusting D2 steel, and hunting for grail knives on the way to **Blade Show Atlanta**.

## 🌟 Key Features

1. **Pioneer Collector Archetypes**:
   - **The Steel Snob**: MagnaCut or bust! Starts with high cash and super steels, but panics if knife condition drops below 85%.
   - **The Whatnot Addict**: Late-night auction fanatic with 5 Express Auction Passes and +25% bidding advantage.
   - **The Budget Hunter**: Loaded with Band-Aids & Silica Gel packs. Highly resilient to scalper markups.
   - **The Knife Modder**: Starts with Torx screwdrivers and Kapex sharpening gear to fix blade play and maintain edge sharpness.

2. **Interactive Minigames**:
   - 🔴 **Whatnot Live Auction Wilds**: Real-time fast-paced bidding war with live chat feeds, opponent bid snipers, and Express Pass auto-sniping!
   - 🔪 **Sharpening & Stropping Station**: Timing minigame to lock in the perfect primary bevel angle and restore razor edges without chipping.

3. **Hilarious Random Incidents**:
   - Cardboard box breakdown staple chips
   - Bank statement interrogation from spouse ("Why did you spend $450 on pocketknives?")
   - Paper-slice thumb cuts (restored with Band-Aids)
   - Humid D2 rainstorms (knives rust without Silica Gel Packs)
   - Scalper Ridge 300% markup flippers

4. **📲 Share Score Feature**:
   - Calculates final **Pioneer Rank** (*Lord of the Grails*, *Blade Show VIP*, *Flipping Veteran*, *Broke Mall Ninja*).
   - Generates clean formatted scorecard ready to copy to clipboard for Discord, Twitter/X, and Reddit r/KnifeSwap.
   - Built-in Web Share API support for mobile devices.

## 🚀 How to Host on GitHub Pages (1-Click Deployment)

This game is built with pure Vanilla HTML5, CSS3, and JavaScript (ES6 Modules) — **zero npm install or build step required!**

### Step-by-Step Instructions:

1. **Push Code to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Pocketknife Pioneers web game"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/PocketknifePioneers.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository on GitHub.
   - Click **Settings** > **Pages** (in the left sidebar).
   - Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and `/ (root)`.
   - Click **Save**.

3. **Enjoy your live game**:
   - Your game will be hosted live at `https://YOUR_USERNAME.github.io/PocketknifePioneers/`!

## 💻 Local Play / Testing

Simply open `index.html` in any modern desktop or mobile web browser, or host locally:

```bash
python -m http.server 8000
# Then visit http://localhost:8000 in your browser
```
